🧩 Hướng dẫn Tạo Custom Markdown Skill (Hot-plug)

Hệ thống hỗ trợ cơ chế Dynamic Markdown Skills cho phép bạn bổ sung kỹ năng chuyên biệt mới chỉ bằng cách tạo một tệp tin SKILL.md trong thư mục skills/<tên-skill>/SKILL.md. Hệ thống sẽ tự động quét và nạp nóng vào Dashboard.

Cấu trúc mẫu của một tệp SKILL.md:

---
id: database-performance-audit
name: Audit Hiệu Năng Cơ Sở Dữ Liệu
description: Phân tích truy vấn SQL, cảnh báo Full Table Scan và đề xuất Composite Index.
version: 1.0.0
tags:
  - database
  - performance
author: Team DevOps
systemInstruction: Bạn là Chuyên gia Tối ưu CSDL MySQL cấp cao. Hãy phân tích kỹ các truy vấn và schema.
---

# HƯỚNG DẪN THỰC THI (PROMPT INSTRUCTIONS)
Đọc hiểu Unified Project Context (Tables, Columns, Indexes, Extracted SQLs).
Tiến hành đối chiếu và xuất báo cáo Markdown chi tiết.
Sau khi lưu file, quay lại Skill Studio và click "Làm mới"
